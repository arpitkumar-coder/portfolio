# Arpit Kumar - GitHub Pages Portfolio

A static portfolio made with HTML, CSS and JavaScript. It is designed to run directly on GitHub Pages without Node.js, PostgreSQL, or environment variables.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy on GitHub Pages
1. Create a GitHub repository, for example `portfolio`.
2. Upload `index.html`, `css/`, `js/`, and `README.md`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Wait for deployment. Your site will be available at the GitHub Pages URL shown there.

## Before publishing
Replace these placeholders in `index.html` and `js/app.js`:
- `YOUR_EMAIL@example.com`
- `YOUR_GITHUB_USERNAME`
- `YOUR_LINKEDIN_USERNAME`

You can also add your GitHub links to individual projects in `js/app.js`.
